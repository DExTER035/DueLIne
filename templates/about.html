About DueLine

A web-based project and task management system with rule-based deadline risk prediction.

Project Overview

DueLine is a student-friendly web application designed to help users organize their academic and personal projects. It tracks projects, tasks, deadlines, estimated work hours, and available working hours to provide clear foresight into upcoming workloads.

By comparing the estimated time needed for a task against the working hours available before its deadline, DueLine helps users identify workload bottlenecks early, prevent last-minute rushes, and finish projects on schedule.

Rule-Based Deadline Risk Classification

DueLine uses predefined rules and mathematical thresholds to evaluate task risk—it does not rely on machine learning or artificial intelligence models. This deterministic approach ensures that status calculations are fully transparent, reliable, and easily explainable during academic project reviews.

Evaluation Precedence

Task status is determined in a clear, sequential order of precedence:

  1. COMPLETED: Completed tasks take top precedence. Once marked finished, a task carries zero remaining risk.
  2. INVALID: Incomplete tasks with missing or unparseable deadlines are flagged as invalid.
  3. OVERDUE: If the deadline date has already passed and the task is incomplete, it is identified as overdue before normal risk classification.
  4. Workload Risk: For incomplete tasks with active deadlines, risk is classified into HIGH, MEDIUM, or LOW by comparing available working hours to estimated work hours.

Status and Risk Classifications

Status Rule Criteria Description
COMPLETED Task is completed The task has been marked finished. Takes highest precedence.
OVERDUE Deadline has passed and task is incomplete Identified before normal risk calculation. Immediate action required.
HIGH Available working hours < Estimated work hours Available working hours are insufficient to complete the estimated work. High risk of missing the deadline.
MEDIUM Estimated hours ≤ Available hours < 1.2 × Estimated hours Available working hours cover the estimated work, but the safety margin is under 20%. Tight schedule.
LOW Available hours ≥ 1.2 × Estimated hours Sufficient working hours are available, including at least a 20% safety buffer for unexpected delays.
INVALID Invalid deadline or negative/non-numeric hours The deadline or risk inputs are invalid, non-numeric, negative, or cannot be parsed.

Project Progress Calculation

Project progress is calculated dynamically from completed tasks compared with total tasks:

Progress (%) = (Completed Tasks / Total Tasks) × 100
  • A task is counted as completed only when its completed status is strictly True.
  • If a project does not have any tasks yet, its progress is safely set to 0%.
  • Progress values are clamped between 0% and 100% to ensure consistent and accessible display.

Technology Stack

DueLine is developed using standard, lightweight technologies without heavyweight database engines or complex frameworks:

Python & Flask

Provides the server-side application logic, URL routing, input validation, and template rendering.

Rule-Based Module (risk.py)

Contains deterministic functions for deadline parsing, available hours estimation, and rule-based risk evaluation.

JSON File Storage (storage.py)

Persists project and task records locally in data.json using Python's built-in json and os.path modules.

HTML & CSS

Delivers a clean, accessible interface with semantic HTML5 elements and responsive styling for desktop and mobile screens.
